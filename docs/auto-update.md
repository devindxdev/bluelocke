# Auto Update

Bluelocke checks for newer GitHub releases automatically.

From v1.27.0, Bluelocke can prompt for newer patch releases when you open the script.

Tap the information icon, or open **Settings > Help & Support > Help & updates**, to view the latest release and choose **Click to Auto Install**.

If your installed script is older than the latest stable release, the update screen offers installation.

**Updating from v1.26.x:** v1.27.0 is a minor release, so older installations can detect it through their automatic update check. Run Bluelocke in Scriptable to see the prompt. If prompts were disabled, open **Help & updates** manually. Keep your existing Scriptable script name to retain saved settings and cache keys.
