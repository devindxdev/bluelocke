# Auto Update

Bluelocke checks for newer GitHub releases automatically.

From v1.26.1, Bluelocke can prompt for newer patch releases when you open the script.

Tap the information icon, or open **Settings > Help & Support > Help & updates**, to view the latest release and choose **Click to Auto Install**.

If your installed script is older than the latest stable release, the update screen offers installation.

**Updating from v1.26.0:** automatic prompts in that version only detect newer minor versions. Open **Help & updates** manually to install v1.26.1. Keep your existing Scriptable script name to retain saved settings and cache keys.
