# Auto Update

Bluelocke checks for newer GitHub releases automatically.

When you open the script, Bluelocke will let you know if a newer version is available.

Tap the information icon in the app, or open **Settings > Help & Support > Help & updates**, to check whether a newer version is available.

If your installed script is older than the latest release, Bluelocke will show you that an update is available.

From v1.26.1 onward, automatic prompts include patch releases. Users on v1.26.0 or v1.26.1-beta.1 can open **Help & updates** to install v1.26.1 manually, since those older builds only prompt automatically for a newer minor version. Keep the existing Scriptable script name so saved settings and sessions carry over.
