# Control Center

Add your Bluelocke shortcuts to your iPhone’s Control Center so you can use them quickly.

## Setup

1. Add a shortcut from the [Siri & Shortcuts page](./shortcuts), such as **Lock** or **Unlock**.
2. Add that shortcut to Control Center using your iPhone’s Control Center settings.
3. Tap it in Control Center to use it.

Give each shortcut a clear name so you can tell what it does. Your iPhone needs an internet connection to use it.
