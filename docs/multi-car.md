# Multi Car

If you use a separate copy of Bluelocke for each car, turn on **Multi Car Support** in each copy’s settings. This keeps their saved car information separate.

## Set Up a Copy for Each Car

1. Make a copy of the script in Scriptable and give it a different name.
2. Turn on **Multi Car Support** in that copy’s settings.
3. Set up the copy for the car and account you want to use.
4. In each widget or shortcut, choose the script for the car you want to control.

Give each copy a name you can recognise, so you can tell which car it is for.
